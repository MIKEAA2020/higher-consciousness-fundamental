Here you can find preprocessed data used in Farnes et al. (Increased signal diversity/complexity of spontaneous EEG, but not evoked EEG responses, in ketamine-induced psychedelic state in humans). The data are divided into two folders ('evoked' and 'sponaneous').

In the 'spontaneous' folder, there are four files for each participant - one for each combination of the conditions (eyes open cs closed and wakefulness vs ketamine). The file names are structured as follows "participantID_date_recordingNumber...". For each participant, the first two recordings are from the awake condition, while the last two are from the ketamine condition. The name also contains information about whether eyes were closed or open. The files should be loded using EEGlab in matlab.

In the 'evoked' folder, matlab data structures are stored containing three variables ('channels', 'times', and 'Y'). The variable 'Y' contains the preprocesessed EEG data in a 3D array (channels by times by trials). The TMS pulse occurred at the 126th sample. The names of the files are structure as "participantID_recordingID_...". Recording ID 31 is from the awake condition, while recordingID 32 is for the ketamine condition. Channels are organized according to Nexstim EEG cap setup.
